漫剧联盟平台使用教程

漫剧联盟是一个企业级大模型 API 聚合与 Token 服务平台。一份文档在手，从零开始：注册账号 → 获取密钥 → 充值额度 → 调用你的第一个 AI 模型，全程只需 10 分钟。

🌐 官网：mjlm.coral-gpu.com 🔌 OpenAI 兼容接口 🎬 配套视频教程：第 1-8 章讲解 + 第 9 章管理后台（见第 8、9 章末尾）

1平台是什么

漫剧联盟是一个大模型 API 聚合平台：它把 DeepSeek、Qwen（通义千问）、Kimi、GLM（智谱）、MiniMax 等国内主流大模型，以及语音、生图、视频生成模型，统一聚合到一个平台，通过一套统一的 OpenAI 兼容接口对外提供服务。

它能帮你做什么？

  • 一站式调用所有大模型：不用分别注册十几个厂商账号，一个 API Key 调用全部模型
  • 业务代码零修改迁移：接口完全兼容 OpenAI 格式，已有项目只需替换 base_url 和 api_key 两个参数
  • 按量付费，价格优惠：按实际消耗的 Token 计费，部分模型相比官网价格有明显折扣
  • 支持 Agent 开发工具：可直接接入 Claude Code、Codex、OpenCode、WorkBuddy/CodeBuddy 等编程助手
💡
什么是 OpenAI 兼容接口？
OpenAI 的接口格式是行业事实标准。只要一个平台"兼容 OpenAI"，就意味着你可以用 OpenAI 官方的 SDK、以及市面上几乎所有支持"自定义 API 地址"的软件（如 Cherry Studio、LobeChat、沉浸式翻译等）来调用它——这就是聚合平台最大的价值。

2注册与登录

打开官网→ 点击「登录」→ 手机号 + 验证码注册→ 进入控制台

2.1 注册账号

  1. 浏览器打开官网 https://mjlm.coral-gpu.com/
  2. 点击右上角「登录」按钮，弹出登录/注册对话框
  3. 切换到「注册」标签，填写：
    • 手机号：输入你的手机号
    • 验证码：点击「发送验证码」，把短信收到的验证码填入
    • 密码：设置密码（至少 8 位）
  4. 勾选同意《服务条款》和《隐私政策》，点击注册

2.2 登录

已注册用户直接在登录框输入手机号 + 密码登录；忘记密码可点击「忘记密码？」，通过手机验证码重置。勾选「保持登录」后一段时间内无需重复登录。

💡
登录成功后会自动进入控制台概览页。如果看到「先完成账号登录，个人账户、钱包和 API 密钥才会生效」的提示，说明还没登录，先登录再操作。

4快速上手三步走

这是控制台概览页官方引导的三个步骤，也是使用本平台最核心的流程：

1

创建 API 密钥

在「API 密钥」页面新建一把密钥，它是调用接口的身份凭证

2

充值额度

在「钱包」页面充值，余额不足接口会返回错误

3

发送首个请求

用 OpenAI 兼容接口发起第一次对话，跑通全流程

第一步：创建 API 密钥（API Key）

  1. 登录后进入控制台，点击左侧导航「API 密钥」
  2. 点击「新建 API 密钥」按钮（新用户会有一个默认key）
  3. 创建成功后，立即复制并妥善保存密钥（形如 sk-xxxxxxxx）
🚨
密钥安全须知：API Key 等同于你账户的支付凭证，谁拿到密钥谁就能消耗你的余额。不要把完整密钥写进前端页面、公开仓库、截图或日志中。如果怀疑泄露，立即到「API 密钥」页删除旧密钥并新建。

第二步：充值额度

  1. 点击左侧导航「钱包」，查看当前余额
  2. 点击充值，选择金额，使用微信支付（扫码）完成付款
  3. 充值到账后即可开始调用。后续可在「概览」页随时查看剩余额度
⚠️
余额不足时接口会返回 insufficient_user_quota 错误。新手建议先小额充值测试，确认调用正常后再按需补充。

第三步：发送首个请求

最简单的方式是用 curl（Windows 10+ / macOS / Linux 均自带）。打开终端，粘贴以下命令并替换密钥：

bash
curl -X POST "https://mjlm.coral-gpu.com:3000/v1/chat/completions" \
  -H "Authorization: Bearer sk-替换为你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-ai/DeepSeek-V4-Flash",
    "messages": [
      { "role": "user", "content": "你好，请用一句话介绍你自己" }
    ],
    "stream": false
  }'

如果返回了类似下面的 JSON（包含 choices 和模型回复内容），恭喜你——调用成功！🎉

json
{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "你好！我是一个大语言模型……"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 45,
    "total_tokens": 57
  }
}
💡
首次调用建议选择便宜的模型练手，例如 DeepSeek-V4-Flash（低价）。模型 ID 一定要用模型广场里展示的完整 ID，不能只写展示名。

5在线体验（免代码）

不想写代码也能玩转大模型。官网首页和控制台提供了在线对话体验功能：

  1. 点击首页右上角的登录控制台，登录后点击左侧的聚合平台即可选择相应模型进行在线体验
  2. 在输入框输入问题，模型即时回复，无需 API Key
  3. 在首页的「模型广场」点击任意模型，也可以进入对应模型的在线体验

建议新手先在这里多试几个模型，比较回复质量和速度，再决定程序中调用哪个。

6.2 先测试连通性：查看可用模型

调用模型列表接口，验证 API Key、Base URL 和网络是否都正常：

bash
curl "https://mjlm.coral-gpu.com:3000/v1/models" \
  -H "Authorization: Bearer sk-替换为你的API密钥"

返回 JSON 里会列出当前可调用的所有模型 ID —— 这些 ID 就是可以填进 "model" 字段的值。

6.3 Python 调用（推荐）

平台兼容 OpenAI 官方 SDK。先安装 SDK（需要 Python 3.7.1+）：

bash
pip install --upgrade openai

然后把 OpenAI 示例中的 base_url 和 api_key 换成本平台的即可，其余代码零修改：

python
from openai import OpenAI

client = OpenAI(
    api_key="sk-替换为你的API密钥",
    base_url="https://mjlm.coral-gpu.com:3000/v1",
)

response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Flash",
    messages=[
        {"role": "system", "content": "你是一位耐心的中文助手"},
        {"role": "user", "content": "用三点说明什么是API"},
    ],
)

print(response.choices[0].message.content)
print(response.usage)  # 本次请求消耗的 Token 数

6.4 Node.js 调用

javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://mjlm.coral-gpu.com:3000/v1",
  apiKey: process.env.CORAL_API_KEY,  // 建议用环境变量存密钥
});

const resp = await client.chat.completions.create({
  model: "deepseek-ai/DeepSeek-V4-Flash",
  messages: [{ role: "user", content: "你好" }],
});

console.log(resp.choices[0].message.content);

7进阶：流式输出与多轮对话

7.1 流式输出（Streaming）

把 stream 设为 true，模型会边生成边返回，大幅降低"首字等待时间"，适合聊天应用。长上下文请求官方也建议配合流式输出：

python
stream = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Flash",
    messages=[{"role": "user", "content": "写一首关于秋天的短诗"}],
    stream=True,
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

7.2 多轮对话

API 本身"没有记忆"，多轮对话需要把历史消息一起发送——每轮都把之前的问答追加进 messages 数组：

python
messages = [
    {"role": "system", "content": "你是一位资深架构师"},
    {"role": "user",   "content": "如何为AI聚合平台设计限流？"},
    {"role": "assistant", "content": "可以从令牌桶算法入手……"},  # 历史回复
    {"role": "user",   "content": "展开讲讲令牌桶的实现"},              # 新问题
]
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Flash", messages=messages
)

7.3 常用参数速查

参数作用建议值
temperature控制随机性：越低越确定，越高越发散问答/代码 0~0.3；写作 0.6~0.9

9管理后台与渠道管理（管理员）

除了面向普通用户的官网，平台还有一个管理后台：https://mjlm.coral-gpu.com:3001。它由浙江睿枢科技基于开源项目 one-api 定制构建（系统名称"漫剧联盟API"），是平台的"调度中枢"——管理员在这里管理上游渠道（对接 DeepSeek、通义、火山引擎等各家厂商的密钥）、令牌、用户、兑换码和调用日志。本章面向管理员和运营人员，从登录到渠道管理一步步讲清楚。

⚠️
权限提示：渠道管理、用户管理等页面仅管理员可见。普通用户账号登录后只能使用令牌、兑换、日志等个人页面；如提示无权限，请联系平台管理员分配权限。后台地址与官网不同，注意末尾端口是 3001。

9.1 登录管理后台

  1. 浏览器打开 https://mjlm.coral-gpu.com:3001，进入登录页
  2. 输入用户名 / 邮箱地址和密码（密码最短 8 位）
  3. 点击「登录」，进入后台首页

登录后首页展示系统状况（名称、版本、启动时间）和系统配置。若没有账号且平台开放了注册，可点击「注册」创建（用户名最长 12 位，密码 8~20 位）；管理员账号通常由平台负责人统一分配。

9.3 渠道管理：列表页解读

打开左侧「渠道」菜单（/channel），进入管理渠道页。列表每行代表一个上游渠道（即一家厂商的一个接入配置），各列含义：

列名含义
ID渠道编号，系统自动分配，日志与模型路由中会引用
名称自定义的渠道名，便于识别（如"DeepSeek 官方-1"）
分组哪些用户分组可使用该渠道（如 default、vip），在设置中配置分组倍率
类型上游厂商类型（OpenAI 兼容、DeepSeek、字节火山引擎等 50+ 种）
状态已启用 / 已禁用（分"手动禁用"与"程序自动禁用"）/ 未测试
响应时间最近一次渠道测试的耗时（秒）
余额上游账户剩余额度，点击可刷新（部分渠道类型不支持，显示 -）
优先级渠道选择优先级，越高越优先；同优先级时随机分流
测试模型点击「测试」按钮时使用的模型，默认优先 gpt-3.5-turbo
操作测试 / 启用 / 禁用 / 编辑 / 删除 / 详情

顶部的搜索框支持按渠道 ID、名称和密钥检索；页面级按钮提供添加新的渠道、测试所有渠道、测试禁用渠道、删除禁用渠道等批量操作。

三条官方提示：① 渠道测试仅支持 chat 模型，优先使用 gpt-3.5-turbo，不可用时自动改用该渠道模型列表的第一个模型；② 部分渠道类型已不支持通过密钥查询余额，余额显示 0 或 - 属正常；③ 点击「详情」可展开余额刷新与额外测试模型设置。

9.4 渠道管理：日常操作速查

测试单个渠道
点击行内「测试」→ 显示"渠道 xx 测试成功，模型 xx，耗时 x 秒"及模型输出
批量测试
「测试所有渠道」一键并发测试；配合监控设置中超时自动禁用，快速发现故障渠道
启用 / 禁用
行内按钮切换。被程序自动禁用的渠道（如超时）修复后可手动启用，或在监控设置中开启"成功时自动启用"
删除
行内「删除」需二次确认；「删除禁用渠道」可一键清理所有已禁用渠道
更新余额
点击余额数字刷新该渠道；支持批量更新所有已启用渠道

9.5 渠道管理：添加一个新渠道（手把手）

点击「添加新的渠道」，按以下顺序填写（以最常用的 OpenAI 兼容类型为例）：

  1. 类型：选择上游厂商类型。绝大多数厂商（DeepSeek、Moonshot、SiliconFlow、各类中转站等）都选 OpenAI 兼容
  2. 名称：自定义，建议带厂商和用途，如"DeepSeek-主力"
  3. 分组：勾选允许使用该渠道的用户分组（新分组需先在「设置 → 倍率设置」中添加）
  4. 模型：选择该渠道支持的模型。可点击「填入所有模型」「填入相关模型」快速填充，或「清除所有模型」重来
  5. Base URL：上游接口地址（仅 OpenAI 兼容等类型需要填），如 https://api.deepseek.com
  6. 密钥：粘贴从上游厂商获取的 API Key。勾选批量创建后可一行一个密钥，批量生成多个相同配置的渠道（多 Key 负载均衡）
  7. 提交 → 提示"渠道创建成功"，列表出现新渠道
  8. 点击该渠道的「测试」按钮，确认返回成功后即可对外提供服务

可选高级字段

  • 模型重定向：JSON 格式，把请求中的模型名替换为另一个。键为请求中模型名称，值为要替换的模型名称：
json
{"my-custom-model": "deepseek-chat"}
  • 系统提示词：强制为该渠道的请求注入指定 system 提示词，配合自定义模型 + 模型重定向使用
  • 代理：填代理站地址（如 https://domain.com），仅替换实际请求的域名部分

9.6 特色功能：模型路由与模型定价

  • 模型路由（设置内）：配置"源模型 → 目标渠道 → 目标模型"的转发规则并设优先级。下游调用源模型名时，系统自动把请求转发到指定渠道的指定模型上——适合模型改名、灰度切换、定制模型名等场景
  • 模型价格（设置内）：按模型配置输入 / 缓存 / 输出三档单价（每百万 Token），未配置的模型走系统默认倍率。视频模型单独按档位定价：Seedance 2.0 按分辨率配置 token 单价（元/百万），MiniMax-H3 按分辨率配置每秒单价（元/秒）

9.7 其他常用页面速览

  • 令牌：创建 API 令牌时可设置额度上限、模型范围（留空不限）、IP 网段限制、过期时间（-1 表示永不过期）；列表页支持一键复制，并能生成 OpenCat / NextChat / LobeChat 的快速接入链接。注意：令牌额度只限制令牌本身，实际用量仍受账户余额约束
  • 兑换与兑换管理：普通用户在「兑换」页粘贴兑换码充值额度；管理员在「兑换管理」页批量生成（设置单个额度 + 生成数量）
  • 日志：「使用明细」按模型/令牌/时间/渠道 ID 筛选，展示输入输出 Token、缓存命中、消耗与耗时；「调用日志」可查看单次请求的下游请求参数、上游返回数据、返回给下游三层完整报文，排查问题必备
  • 用户管理：调整用户额度、封禁/激活账号、普通用户与超级管理员角色升降级
  • 设置：运营设置含充值链接、聊天页面链接、失败重试次数、单位额度换算；额度设置含新用户初始额度、邀请奖励；监控设置含最长响应时间（超时自动禁用渠道）、失败自动禁用、成功自动启用；另有倍率设置（模型/补全/分组倍率 JSON）、公告与首页内容（支持 Markdown）
  • 运营看板 / 安全防护（仅超级管理员）：实时在线人数、请求量、资源压力与数据库连接观测；防御等级分标准/加强/严格三档，配合安全事件分析与人工处置审计使用
💡
新管理员上手建议路径：登录 → 渠道页看懂列表 → 给一个测试渠道跑通「测试」→ 令牌页创建一个令牌并实际调用一次 → 日志页核对该次调用明细。走完这条链路，后台的核心逻辑就通了。
